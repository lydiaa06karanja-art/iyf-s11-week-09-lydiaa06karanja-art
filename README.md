
# Week 9: Effects, Data Fetching & Routing

This repository contains my solutions for Week 9 of the IYF React course.
Focus: Building CommunityHub into a multi-page application with real data using React Hooks, API integration, and React Router.

## 📚 Lessons Covered

### Lesson 17: Effects, Data Fetching & Routing
Learned how to handle side effects, fetch data from APIs, and implement client-side routing.

**Key Concepts:**
- `useEffect` Hook and dependency arrays
- Fetching data from APIs with `async/await`
- Cleaning up effects to prevent memory leaks
- React Router for multi-page navigation
- Loading and error states for data fetching

### Lesson 18: Component Libraries & Styling
Built reusable UI components and implemented styling with CSS Modules and Tailwind CSS.

**Key Concepts:**
- Creating reusable components: Button, Input, Card, Modal, Avatar
- CSS Modules for scoped component styling
- Tailwind CSS for utility-first styling
- Component props: variants, sizes, and states
- Responsive design patterns
